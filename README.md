# AR Pengenalan Hardware

## About
Aplikasi Augmented Reality untuk mengenalkan komponen hardware komputersecara interaktif.

## Features
-Interactive 3D Hardware Visualization: Menampilkan model 3D komponen komputer (seperti PC, Monitor, dan Keyboard) yang dapat diamati dari berbagai sudut pandang menggunakan teknologi Augmented Reality.
-Marker-Based AR Tracking: Memanfaatkan teknologi Vuforia untuk mendeteksi marker fisik secara presisi agar objek 3D komponen hardware dapat muncul secara stabil di atas permukaan meja.
-Informative Component Breakdown: Menyediakan informasi teks dan penjelasan interaktif mengenai fungsi serta spesifikasi dari masing-masing komponen hardware yang dipilih pengguna.
-Responsive User Interface: Dilengkapi menu navigasi dan tombol interaktif yang intuitif untuk memudahkan pengguna beralih antar komponen hardware.

## Tech Stack
- Unity
- C#
- Vuforia

## My Role
-Lead Developer & Unity Programmer: Bertanggung jawab membangun struktur proyek di Unity, menulis skrip C# untuk interaktivitas, serta mengonfigurasi integrasi Vuforia Engine.
-AR Asset & Scene Integrator: Mengatur pemetaan objek 3D hardware, pencahayaan (lighting), dan skala model agar tampil optimal di perangkat mobile berbasis kamera.
